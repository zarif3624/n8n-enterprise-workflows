# Workflow automation ROI model

Use a conservative model and publish assumptions next to results.

## Capacity value

```text
annual capacity value = annual workflow volume
                      x minutes saved per execution
                      x loaded hourly cost
                      / 60
```

## Error avoidance

```text
annual avoided loss = annual workflow volume
                    x baseline error rate
                    x expected error reduction
                    x average cost per error
```

## Revenue impact

```text
annual revenue impact = eligible annual volume
                      x expected conversion or retention lift
                      x average economic value
```

## Total cost

Include implementation, licenses, infrastructure, review time, maintenance,
monitoring, and change management. Do not treat every saved minute as headcount
reduction. Capacity, speed, quality, risk reduction, and employee experience are
different benefit categories.

## Recommended reporting

Report a range with conservative, expected, and optimistic cases. Track the
assumptions that materially affect the result, then replace estimates with
observed values after launch.
