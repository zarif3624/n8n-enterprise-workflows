# Agent instructions

This repository contains n8n workflows. Before changing workflow JSON, nodes,
expressions, error handling, credentials, or MCP integrations, use the official
n8n skills from `n8n-io/skills`, beginning with
`using-n8n-skills-official`.

Never add secrets, API keys, credential IDs, production URLs, customer data, or
personal data. Keep templates inactive. Run `npm run check` before committing.
For every workflow addition, include adoption instructions, sample input,
business value, an ROI model, and security considerations.
